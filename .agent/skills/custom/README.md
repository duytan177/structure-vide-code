# HƯỚNG DẪN TẠO SKILL ĐẶC THÙ CHO DỰ ÁN (custom/README.md)

Thư mục này dành riêng cho việc chứa các **Custom Skill đặc thù** của dự án hiện tại (các quy trình công việc không có trong bộ skill dùng chung chuẩn).

---

## 💡 KHI NÀO NÊN TẠO CUSTOM SKILL?

Tạo Custom Skill trong thư mục này khi dự án của bạn có:
1. Quy trình tích hợp riêng với bên thứ 3 (Ví dụ: `vnpay-mock-payment-skill.md`).
2. Quy trình sinh code tự động đặc thù (Ví dụ: `generate-grpc-proto-skill.md`).
3. Quy trình migration dữ liệu hoặc seed test data đặc thù doanh nghiệp.

---

## 📝 ĐỊNH DẠNG FILE CUSTOM SKILL

Mỗi file custom skill nên tuân theo định dạng:
```markdown
# CUSTOM SKILL: [TÊN SKILL SE DÙNG]

## 🎯 MỤC TIÊU
Mô tả ngắn gọn skill này dùng để làm gì.

## 📋 CÁC BƯỚC THỰC THI (PROCEDURE)
1. Bước 1...
2. Bước 2...
3. Bước 3...
```
